Welcome Reviewer!

This package contains a complete, reproducible validation of the
Mesche's Tensor Dynamics Framework (MTDF) against 15 independent
scalar empirical tests plus 4 strict vector likelihood pillars and
1 CMB distance-prior diagnostic (excluded from strict totals).

KEY RESULTS:
  Scalar pillars:   14/14 counted scalar pillars pass at 1 sigma; the S8
                    and fsigma8 rows are shown as "(cont.)"
                    PREDICTION-CONTESTED and are never counted as passes
                    (the dashboard displays the combined tally
                    17/19 + 2 (cont.))
  Combined strict:  chi^2/nu = 1.17  (DOF = 1741, includes vector data)

NOTE ON EXTERNAL DATA:
  Two datasets require manual placement because their providers do not
  allow scripted download:
    1. DESI BAO: place the files under validation/data/External/bao_desi/
       (scripts/download_bao.sh prints the exact filenames and instructions)
    2. DESI VAST voids: see scripts/download_desi_voids.sh
  Without the DESI BAO files the combined strict chi^2/nu = 1.17 headline
  cannot be regenerated; the shipped output/Validation_Dashboard_V75.html
  contains the full result for inspection.

REPRODUCIBILITY:
================================================================================

From the repository root:

  bash setup_environment.sh
  source venv/bin/activate
  cd validation/code
  python run_validate.py \
      --workbook ../data/DB_Workbook_STRICT_V19.xlsx \
      --out ../output/My_Dashboard.html \
      --diag ../output/My_Diagnostics.csv

This writes to My_Dashboard.html / My_Diagnostics.csv so the shipped V75
baselines are never overwritten. Compare against the shipped
Validation_Dashboard_V75.html / Diagnostics.csv: the results should be
identical (except timestamps).
